# Login and Registration System in C++

## About the Project
This is a simple console-based Login and Registration System developed using C++. It allows users to register with a username and password and log in using their saved credentials. The program uses file handling to store and retrieve user information from a text file.

## Features
- User registration
- Username duplication checking
- Login authentication
- File handling using `fstream`
- Stores user credentials in `users.txt`
- Menu-driven program
- Exit option

## Technologies Used
- C++
- iostream
- fstream
- string

## How It Works
1. Select Registration to create a new account.
2. Enter a username and password.
3. The program checks whether the username already exists.
4. User information is saved in `users.txt`.
5. Select Login and enter the registered credentials.
6. The program displays a success or error message.
7. Select Exit to close the program.

## How to Run
1. Clone or download this repository.
2. Open `Task#2.cpp` in a C++ IDE or compiler.
3. Compile and run the program.
4. Choose an option from the menu.
